# Unity MMORPG 自动化测试平台 - 规则文档

本文档约定项目结构、代码风格、API 与扩展规则。

---

## 一、项目约定

### 1.1 技术栈

- **编排服务（v2）**：Go（`server/`，仅标准库），单二进制；API 与 legacy 版完全一致，存储文件格式兼容。
- **Agent（v2）**：Rust（`agent/`），单二进制、目标机无需 Python 运行时；Android AI 探索测试为原生 adb 实现。
- **编排服务（legacy）**：Python 3.10+ / FastAPI / Uvicorn（`main.py`，保留可用）；Mac / Linux / Windows 通用。
- **Agent（legacy）**：Python 3 脚本（`agents/runner_*.py`，保留可用），通过 HTTP 与编排服务通信。
- **存储**：当前为内存 + `data/runs/*.json`；可扩展为 SQLite/PostgreSQL。
- **前端**：单页 HTML + 原生 JS，Tailwind CDN（三端共用）。

### 1.2 目录规范

- `server/`：Go 版编排服务（v2）；`agent/`：Rust 版 Agent（v2）。
- `main.py`：legacy 编排服务逻辑；`run_server.py`：legacy 启动入口。
- `agents/`：Agent 脚本；`runner_common.py` 为公共逻辑，`runner_<platform>.py` 为各环境。
- `static/`：仅前端资源。
- `data/runs/`：任务结果 JSON，自动创建。
- `docs/`：说明文档、规则文档、技术方案。
- `scripts/`：运行与构建脚本（run.sh、run.bat、build.sh、build.bat）。
- `config/`：配置示例（如 `.env.example`）。
- `.github/workflows/`：CI 示例（供复制到 Unity 项目使用）。

### 1.3 环境与依赖

- 依赖通过 `pip install -r requirements.txt` 默认安装；README/说明文档以 Mac 为例。
- Agent 仅依赖 Python 标准库 + 编排服务 HTTP 接口（无额外 pip 包）。
- **可选集成**（Airtest 执行引擎、AI 探索测试）按需安装 `requirements-airtest.txt`；集成模块一律延迟导入，依赖缺失时返回明确错误信息而非抛异常（同 `gpt_testgen` 模式）。

## 二、代码风格

### 2.1 Python

- UTF-8，4 空格缩进；公开接口建议类型提示与文档字符串。
- 命名：小写下划线（变量/函数）、大驼峰（类）、全大写下划线（常量）。
- 路由与复杂逻辑加简要注释。

### 2.2 API 与数据

- REST：读用 GET，写用 POST；列表统一 `{ "items": [...], "total": N }`；错误用 HTTP 状态码 + 报文。
- Agent 注册/心跳/拉取/上报的字段以 Pydantic 模型为准，新增字段时同步更新文档。

### 2.3 Agent

- 各 runner 实现 `run_*_test(job) -> (success, log_path, summary)`，内部可替换为真实 Unity/ADB 调用。
- 集成类任务（`extra.job_type` 为 `airtest` / `ai_exploratory`）由 `runner_common.dispatch_integrations` 统一分发；runner 命中后直接上报结果，未命中（`handled=False`）继续走自身逻辑。新增集成类型时：`integrations/` 下新建延迟导入的执行模块 + `dispatch_integrations` 增加 job_type + `modules/skills.py` 注册技能 + 同步文档与测试。
- 公共逻辑集中在 `runner_common.py`，避免重复。

## 三、扩展与维护

### 3.1 新增 API

- 在 `main.py` 中注册路由；若需请求体，使用 Pydantic 模型。
- 在 **说明文档.md** 的「API 说明」中补充路径、方法、请求/响应示例。

### 3.2 新增存储（如 SQLite）

- 可引入 `sqlite3` 或 ORM，将任务与结果持久化；保留 `data/runs/` 或改为 DB 路径配置。
- 同步更新 **说明文档.md** 与 **规则文档.md**。

### 3.3 文档同步

- 修改安装步骤、环境要求、API 行为时，同步更新 **README.md** 与 **说明文档.md**。
- 新增目录、命名或技术约定时，更新 **规则文档.md**。
