# Unity3D MMORPG 自动化测试平台 - 技术方案

> ## v2 架构（当前）：编排服务 Go + Agent Rust
>
> API 协议、Web 看板（`static/`）与数据文件格式（`data/`）与 v1 完全兼容，三端可混用。
>
> | 组件 | v1（legacy，保留可用） | v2（当前） | 说明 |
> |---|---|---|---|
> | 编排服务 | Python / FastAPI（`main.py`） | **Go**（`server/`，仅标准库） | 单二进制部署，`go build` 即可 |
> | Agent | Python 脚本（`agents/runner_*.py`） | **Rust**（`agent/`） | 单二进制，目标机无需 Python 运行时 |
> | AI 探索测试 | `integrations/ai_agent.py`（依赖 airtest + openai） | **Rust 原生 adb 实现**：截图 `adb exec-out screencap -p`、操作 `adb shell input`、OpenAI 兼容视觉接口 | Android 端零 Python 依赖 |
> | Airtest 引擎 | `integrations/airtest_executor.py` | Rust 分发调用 airtest CLI（Python 可选安装） | 图像识别复用 Airtest 生态 |
> | 看板 / 数据 | `static/` + `data/*.json` | 复用同一套 | 文件格式一致 |
>
> 任务协议不变：`extra.job_type` 支持 `generate_and_run` / `airtest` / `ai_exploratory`。
> 以下 v1 技术方案内容保留作为 legacy 参考。

## 一、目标与范围

- **目标**：为 MMORPG 类 Unity3D 游戏提供自动化测试平台，支持调度、执行、结果收集与多环境运行。
- **环境**：Mac、Linux、Windows、iOS、Android（含模拟器/真机）。
- **能力**：单元/集成测试（Unity Test Framework）、可选 UI/黑盒自动化（AltTester）、CI 集成（GameCI/GitHub Actions）。

---

## 二、可行技术栈

### 2.1 Unity 侧（游戏项目内）

| 技术 | 用途 | 平台 |
|------|------|------|
| **Unity Test Framework** | Edit Mode / Play Mode 测试，NUnit 风格，命令行可跑 | Win/Mac/Linux/Android/iOS |
| **Play Mode in Player** | 打成独立包后跑测试，贴近真机/桌面环境 | 同上 |
| **Unity Automated QA**（可选） | 触控录制回放、云设备农场 | 主要移动端 |
| **AltTester Unity SDK**（可选） | UI 对象查找、点击/滑动、截图，支持 C#/Python/Java | Win/Mac/Android/iOS（Linux 需查版本） |

### 2.2 编排与执行（本平台）

| 层级 | 技术选型 | 说明 |
|------|----------|------|
| **编排服务** | Python 3.10+ / FastAPI | 调度任务、接收 Agent 上报、存结果、简单看板 |
| **存储** | SQLite / JSON 文件 | 先单机可运行，后续可换 PostgreSQL |
| **Agent 脚本** | Python 3 | 各 OS 统一用 Python 驱动 Unity/命令行/设备 |
| **前端看板** | 单页 HTML + JS（或后续 Vue/React） | 查看任务、运行、结果 |

### 2.3 各环境执行方式

| 环境 | 执行方式 | 备注 |
|------|----------|------|
| **Windows** | Unity Editor 命令行 / 独立 Player + Test Framework；可选 AltTester | 需安装 Unity，Agent 调 `Unity.exe` 或 Player |
| **Mac** | 同上；iOS 需 Xcode + 模拟器或真机 | Agent 调 Unity 或 `xvfb-run` 无头（仅 Linux 常用） |
| **Linux** | Unity Editor 无头（`-batchmode -nographics`）或 Player；无显示器时用 `Xvfb` | GameCI 常用 Linux 跑 Test Runner |
| **Android** | 打 APK 后：真机/模拟器 + ADB；或 Unity Test Framework 打测试包 | Agent 用 ADB 安装、启动、拉日志；可选 AltTester |
| **iOS** | 需 Mac：模拟器或真机；Unity 打 Xcode 工程，用 xcodebuild / XCUITest / Appium | 真机需证书；AltTester 支持 iOS |

### 2.4 CI/CD

| 技术 | 用途 |
|------|------|
| **GameCI (game-ci/unity-actions)** | GitHub Actions 内跑 Unity 构建与 Test Runner，矩阵支持 Win/Mac/Linux/iOS/WebGL 等 |
| **GitHub Actions matrix** | 多平台并行：`StandaloneWindows64`、`StandaloneOSX`、`StandaloneLinux64`、`Android`、`iOS` |
| **本平台** | 可被 CI 触发（webhook）或定时触发，由平台下发给各环境 Agent 执行，统一收结果 |

## 三、架构概览

```
                    ┌─────────────────────────────────────┐
                    │  编排服务 (FastAPI)                   │
                    │  - 任务队列 / 调度                    │
                    │  - Agent 注册 / 心跳                  │
                    │  - 结果写入 DB 或文件                 │
                    │  - 简单 Web 看板                      │
                    └──────────────┬──────────────────────┘
                                   │ HTTP / WebSocket
         ┌─────────────────────────┼─────────────────────────┐
         │                         │                         │
         ▼                         ▼                         ▼
  ┌──────────────┐         ┌──────────────┐         ┌──────────────┐
  │ Windows Agent│         │  Mac Agent   │         │ Linux Agent  │
  │ Unity+Player │         │ Unity+iOS    │         │ Unity+Xvfb   │
  └──────────────┘         └──────────────┘         └──────────────┘
         │                         │                         │
         ▼                         ▼                         ▼
  ┌──────────────┐         ┌──────────────┐         ┌──────────────┐
  │Android Agent │         │  iOS Agent   │         │  (可选)      │
  │ ADB/模拟器   │         │ 模拟器/真机   │         │ 云设备/农场   │
  └──────────────┘         └──────────────┘         └──────────────┘
```

- **编排服务**：唯一中心，部署在 Mac/Linux/Windows 任一均可。
- **Agent**：每台执行机（或每环境一种）跑一个 Agent，向中心拉取任务、执行 Unity/Player/ADB、上报结果。
- **Unity 项目**：使用 Unity Test Framework（+ 可选 AltTester），由 CI 或 Agent 触发构建与测试。

## 四、框架与工具选型汇总

| 类别 | 选型 | 跨平台说明 |
|------|------|------------|
| 测试框架（Unity 内） | Unity Test Framework (NUnit) | 官方支持，Win/Mac/Linux/Android/iOS |
| UI/黑盒（可选） | AltTester Unity SDK | Win/Mac/Android/iOS |
| 编排与 API | FastAPI (Python) | Win/Mac/Linux 通用 |
| Agent 语言 | Python 3 | 各 OS 均有 Python，便于驱动命令行与 ADB |
| CI | GameCI + GitHub Actions | 矩阵多平台构建与测试 |
| Linux 无头 | Unity `-batchmode -nographics` 或 Xvfb | 仅 Linux |
| 移动端驱动 | ADB (Android) / Xcode/Appium (iOS) | 标准方案 |

---

## 五、实施阶段建议

1. **Phase 1**：编排服务 + 单环境 Agent（如 Windows 或 Mac），仅跑 Unity Test Framework 的 Play Mode 测试，结果落库/文件。
2. **Phase 2**：扩展 Agent 到 Linux、Android（APK + ADB）、iOS（Mac + 模拟器），GameCI 示例 workflow 打通。
3. **Phase 3**：可选接入 AltTester、Unity Automated QA 或云设备，丰富 UI 与端到端场景。

以上技术栈与架构可适应 Mac、Linux、Windows、iOS、Android 各类环境，并随项目逐步扩展。
